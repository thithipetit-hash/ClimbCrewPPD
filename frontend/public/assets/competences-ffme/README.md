# Illustrations officielles FFME — copie locale

Ces rendus JPEG correspondent aux pages intégrales, sans retouche, des 12 PDF techniques
FFME référencés dans `frontend/src/lib/competences-ffme.js`. Leur incorporation à
CristalClimbClub est effectuée sur déclaration de l'exploitant disposant des droits.

- Source et titulaire : Fédération française de la montagne et de l'escalade (FFME).
- Le nom et la source restent crédités dans l'application.
- Fichiers générés par `node frontend/scripts/download-ffme-illustrations.mjs`.
- `manifest.json` recense les pages ; pas de requête à FFME pendant la consultation.
- Ne pas modifier les pages techniques dans une application liée à la sécurité.
- Vérifier les mises à jour officielles, notamment pour le tableau de matériel.
